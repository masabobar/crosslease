## 🔴 Start here — template creation is broken on dev

Publishing a Bank Product Template returns **500 `PRODUCT_TEMPLATE_CODE_GENERATION_ERROR`** — "Failed to
generate a unique template code. Please try again."

**Retrying can never succeed.** This is not filed in Jira; this brief is the record.

Backend, `product_templates/application/services.py:70-79`. The five-attempt retry loop mutates no state,
so every pass computes the same candidate. That candidate is `count + 1`, but `template_code` is assigned
once and immutable while the count is a live aggregate over versions — once the two diverge, the failure is
permanent for that tenant and financing type.

Reproduce in three API calls: create a `full_refinancing` template, `PATCH` its draft's `financing_type`
to `partial_refinancing`, then create another `full_refinancing` template → 500.

**No frontend change can fix this.** The fix is to derive the suffix from the highest issued suffix, or use
a real sequence. The FE already translates the error, so it reads correctly once dev picks that up.
